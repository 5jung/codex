# 실사용 흐름 점검 — 2026-10-15

세종에서 영유아와 외출하며 수유실을 찾는 흐름을 기준으로 점검했다. 모바일 크기의 Chromium과 실제 Kakao SDK/장소검색을 사용했다. 휴대폰 실기기 현장 이용이나 실제 수유실 존재·운영 상태를 확인한 것은 아니다.

## 추가로 표시하는 정보

Kakao Places 응답이 실제 제공한 도로명/지번 주소, 건물·장소 분류, 전화번호를 사용한다. 기존 공식 자료의 시설 내 층·위치·이용 대상·전화번호도 상세에서 표시한다. 카카오 장소 상세로 이동해 추가 정보를 확인할 수 있다. 자체 서버나 장기 저장소에 Kakao 결과를 복제하지 않는다.

카카오 후보는 확인된 수유실이 아니다. 건물 전화번호를 수유실 직통 전화로 표현하지 않는다. 운영시간·기저귀 교환대·주차·유모차 진입·보호자 동반 여부는 출처가 제공하지 않으면 미확인으로 남긴다.

## 검증 범위

- 실제 세종 GPS 좌표를 모사한 위치 권한 허용·거부, 실제 지도 타일·마커·장소검색·지도 영역 재검색.
- 모바일 목록 터치 드래그·취소·키보드 조작, 상세 펼치기·접기, 지도 집중 보기와 작은 화면 배치.
- 계정 생성·로그인·후기·수정 제보·로그아웃·복구·탈퇴 및 관리자 처리·데이터 소유권 기존 검증.
- 설치 manifest·아이콘·설치 안내, 주소 복사·전화/장소/길찾기 링크.
- 통제된 SDK 응답으로 지도 중심 보존, 늦은 응답 무시, 새 영역 검색 파라미터, 검색 오류 재시도 검증.

실제 외부 길찾기 앱의 경로 품질·현장 시설 정보·iOS/Android 홈 화면 설치 완료는 별도 실기기 확인이 필요하다. 전국 수유시설 API는 승인과 이용 조건 확인 대기 중이며, 카카오 후보의 저장·후기·제보는 아직 제공하지 않는다.

## 사용자 추가 사례: AK& 세종

공식/지도 키워드 데이터에 없는 실제 방문 시설을 찾을 수 없는 사례를 반영했다. 공개 방문 후기 두 건을 읽고 원문·작성일·위치 설명을 별도 근거로 표시한다. `AK 세종`, `AK&세종`, `세종 AK몰`, `에이케이 세종`의 명칭 변형도 검색한다. 공식 확인과 방문 후기를 구분하고 현재 보호자 출입 조건과 유모차 동선은 미확인으로 남긴다. 사용자 제공 원문을 대조한 결과 주소가 다른 가름로 143 후기는 제외하고, 한누리대로 411의 AK&로 분리했다. 상세에서 방문 후기 검색 링크를 제공해 다른 누락 장소의 근거를 찾는 경로도 추가했다.

첫 보완은 AK& 세종 한 곳의 수동 검토 기록이었다. 이후 9곳을 더한 현황은 [세종 보완 범위](SejongCoverage.md)를 참고한다. 전국 블로그 자동 분석·미등록 시설의 신규 제보 접수/관리 자동화는 아직 제공하지 않는다. 기존에 등록된 시설의 후기·수정 제보는 사용할 수 있다.
