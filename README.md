# 수유실 지도

대한민국 수유실 찾기 모바일 웹앱의 개발 버전이다. 현재 부산·대구 1호선·성남·제주·인천 부평 공식자료 429건을 제공하며, 이 중 부산 291건에 원본 좌표가 있다. 전국 전체를 제공하지 않는다. 예시 데이터는 별도 버튼으로 구분한다.

구현: 검색·지도·시설 목록/상세, 운영시간 정보·기저귀 교환대 필터, 현재 위치 요청·직선거리 정렬, 지도 영역 검색, 외부 카카오 길찾기, 계정·후기·수정 제보·신고·관리자 검토. 원본 운영시간·편의시설 누락과 현장 상태의 변동은 상세 안내를 확인한다.

## 클라우드에서 시작

필요 도구: Node.js 24, npm, Python 3.12, Docker. 현재 개발 환경에서 검증했다.

```sh
cd /workspace/codex
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev:all
```

명령은 개발용 MariaDB, API, 웹을 순서대로 준비하고 검증된 기존 서비스는 재사용한다. DB는 loopback 33306, API는 loopback 3001, Vite는 5173을 사용한다. 개발 웹 서버는 클라우드용으로 0.0.0.0에 바인딩하므로 인터넷에 직접 공개하지 않는다. 클라우드 온보딩 UI는 웹 미리보기를 지원하지 않는다.

DB 데이터와 생성된 개발용 자격 정보는 `/workspace/.nursing-runtime`에 두며 저장소에 포함하지 않는다. Docker 컨테이너 프로세스는 새 환경에서 다시 시작해야 한다. DB 컨테이너는 SHA-256 digest로 고정한 MariaDB 11.4 이미지다. 운영 서버의 구성은 별도로 준비해야 한다.

프로세스별 직접 실행:

```sh
npm run db:start
npm run db:init
npm run dev:api
# 별도 터미널에서
npm run dev -- --port 5173 --strictPort
```

통합 명령이 시작한 API 로그는 `/workspace/.nursing-runtime/api.log`에 기록한다. 프로세스 상태가 정상이라면 재실행해도 중복 시작하지 않는다. 다른 서비스가 포트를 사용하면 임의로 종료하지 않는다. 개인 PC에서는 `/workspace`에 고정된 개발 helper의 경로를 OS에 맞게 조정해야 하며, 아직 Windows/macOS 전체 설치 검증을 수행하지 않았다.

## 카카오 지도

`VITE_KAKAO_MAP_KEY`는 환경 설정의 런타임 변수로 전달한다. 개인 PC에서는 `.env.example`을 `.env.local`로 복사해 브라우저용 JavaScript 키를 설정할 수 있다. REST API 키와 Admin 키를 넣지 않는다. `VITE_` 변수는 브라우저 번들에 포함되며 비밀 저장 용도가 아니다. 키 값은 채팅에 보내지 않는다.

Kakao Developers에서 앱의 카카오맵 사용 상태를 ON으로 하고 JavaScript 키에 `http://localhost:5173` 등 실제 접속 도메인을 등록한다. 공개 배포는 HTTPS 도메인을 등록한다. 키 변경 후 개발 서버 재시작과 재빌드가 필요하다. 현재 키로 SDK HTTP 200 및 브라우저 지도 초기화를 확인했다.

키가 없거나 지도가 실패해도 목록을 사용할 수 있다. 가상 예시와 좌표가 없는 시설에는 마커·길찾기를 제공하지 않는다. 현재 위치는 사용자가 버튼을 누를 때만 요청해 브라우저 메모리에서 사용한다. 지도 제공사에는 지도 표시를 위한 조회가 발생하며 위치를 자체 API/DB에 저장하지 않는다.

## 후기·제보와 관리자

검색은 로그인 없이 가능하다. 후기·제보는 영문/숫자/밑줄/하이픈 아이디와 12자 이상 비밀번호로 가입해 작성한다. 비밀번호는 scrypt+개별 salt로 해시하고 세션 토큰도 DB에는 해시로 저장한다. 쿠키는 HttpOnly/SameSite이며 운영 모드는 Secure를 적용한다. 가입 시 복구 코드를 제공하고 비밀번호 변경·일회용 코드 복구·회원 탈퇴를 지원한다. 복구 코드 재사용은 차단하고 세션을 만료한다. 개인정보/보관 정책과 실제 HTTPS 배포는 아직 준비가 필요하다.

후기는 관리자 검토 전까지 작성자에게만 보인다. 본인 후기 삭제, 신고 접수, 수정 제보 상태 확인을 지원한다. 관리자는 승인·반려, 신고 후기 숨김, 처리 이력과 기본 수치를 확인할 수 있다. 승인된 수정값은 원본과 분리해 저장한다.

기본 관리자와 고정 비밀번호는 없다. 운영자가 개발 계정을 생성한 뒤, 해당 기존 계정을 다음 명령으로 관리자 권한에 지정한다.

```sh
npm run admin -- existing_handle
```

이 명령은 클라우드 개발용이며 관리자 권한을 얻는 공개 API는 없다. 테스트 계정은 테스트 종료 시 삭제한다. 현재 실제 운영자 계정은 아직 지정하지 않았다.

## 검증

```sh
npm test
npm run test:data
npm run test:api
npm run test:e2e
npm run build
npm run typecheck:server
```

API 테스트는 실행 중인 개발 API/DB에 일시적인 테스트 시설·계정을 만들고 정리한다. 운영 DB에서 실행하지 않는다. 브라우저 테스트는 `/usr/bin/chromium`을 사용하며 실제 카카오 테스트에는 키가 필요하다. 키가 없는 환경의 실제 지도 테스트는 명시적으로 skip한다. 프록시 환경에서는 외부 HTTPS를 환경 CA를 신뢰하는 Playwright Node transport로 검증 후 브라우저에 전달한다. TLS 검증을 끄지 않는다. 인증키가 URL에 포함될 수 있어 브라우저 HAR/trace/네트워크 원문을 저장하지 않는다.

데이터 출처·이용 조건·전국 API 신청 안내는 [DataSources.md](DataSources.md), 지도 비교는 [MapComparison.md](MapComparison.md), 잔여 개발 범위는 [ToDo.md](ToDo.md)를 참고한다.

비공개 테스트 배포 구성·검증 범위·남은 조건은 [docs/PrivateBeta.md](docs/PrivateBeta.md)를 참고한다.

지도 중심 UI: 데스크톱 탐색 패널·모바일 하단 상세·마커 묶음을 지원하며, 하트로 저장한 장소는 현재 브라우저에만 보관한다. 계정·데이터 범위 안내는 헤더 버튼에서 연다. 예시 데이터 전환도 이용 안내 안에 있다.
